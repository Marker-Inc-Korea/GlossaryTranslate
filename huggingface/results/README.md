# GlossaryRAG Translate public benchmark results

This repository contains aggregate evaluation tables and runtime metadata for the
GlossaryRAG Translate reference implementation. It does not redistribute benchmark
source text, reference translations, terminology dictionaries, or raw predictions.

The evaluation uses TICO-19 (CC0) and WMT25 Terminology Shared Task material
(CC BY-NC 4.0), downloaded directly from their official upstream sources. The
GlossaryRAG Translate software is Apache-2.0. Dataset and model licenses remain
independent.

See `public-benchmark.md` for the result table and paired confidence intervals.
