# Changelog

## 0.1.0 - 2026-11-15

- Added CSV, TSV, JSONL, and TBX glossary loading.
- Added reusable Trie retrieval with longest-overlap resolution, source priority,
  ASCII word-boundary checks, and common English inflection support.
- Added structured model-neutral glossary prompts and local OpenAI-compatible inference.
- Added resumable no-term, proper-term, and random-term benchmark execution.
- Added BLEU, chrF, terminology-success, and paired bootstrap evaluation.
- Added public TICO-19 and WMT25 medical, IT, and finance benchmark adapters.
- Added GitHub CI and Hugging Face Space/result-dataset export tools.
