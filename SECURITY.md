# Security policy

Report suspected vulnerabilities privately through the GitHub security advisory
feature after the public repository is created.

Glossaries and source documents may contain confidential information. Use a local or
private model endpoint, restrict network access, and avoid uploading confidential data
to a public Hugging Face Space. Glossary rows and source text are treated as data, but
prompt-based separation is not a substitute for authentication, authorization, input
limits, logging controls, or deployment isolation.
